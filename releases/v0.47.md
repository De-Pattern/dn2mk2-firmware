# v0.47 · TUNED

patcher: de-pattern.github.io/dn2mk2/patcher.html

a small release: the Monomachine's TUNE as the Monomachine shows it, a quieter TRIM preview, and BOUNCE out of MACHINE SEL while it's rebuilt

**Monomachine TUNE**
- TUNE on the Monomachine machines (SID, VO-6, WAVE, DDRW, DENS) reads -64..+63 as on the Monomachine, 0 in the middle, instead of a percent (the whole knob is ±2 semitones, as on the Monomachine)
- FUNC + turn jumps a semitone at a time (-64, -32, 0, +33, +63); a plain turn is as before, every step

**quieter preview**
- the TRIM preview after a recording was 6 dB louder than v0.37..v0.39 (v0.40 started normalising takes to full scale). it is back at the older level. the recording itself is unchanged: it plays from its slot at the level it always did

**recorder**
- the INTO box on the RECORDER is smaller, so it no longer crowds the controls beside it

**BOUNCE hidden**
- BOUNCE is no longer in MACHINE SEL: on the unit it recorded but never played back. projects with BOUNCE tracks still load and play as before. it comes back as FLEX, rebuilt from the ground up and tested with both processors running together

**safety**
- the gate's reuse cache could take a pass recorded in another copy of the code as this build's; it now refuses those, so every reused check really is this build's

**test**
1. a Monomachine track: turn TUNE: -64..+63, 0 in the middle; FUNC + turn: -64, -32, 0, +33, +63; the pitch moves a semitone each FUNC step
2. record something, TRIM, FUNC + YES: the preview is quieter than v0.46's (about half), still clearly heard over the pattern
3. the saved recording plays from its slot at the same level as in v0.46
4. MACHINE SEL: BOUNCE isn't listed. an old project with a BOUNCE track loads and plays
5. everything from v0.46

**known issues**
- FASCIA isn't in this release: it is being rebuilt as a one-voice machine light enough for the DSP
- everything listed for v0.46 except BOUNCE's (it is out of the list)

**Coming next (not available yet)**
- v0.48: BOUNCE's code removed (old projects still load), the RECORDER's text always inside its place (R.LEN's MAX on one line), the old open reports checked again in the emulator, KEYBOARD mode kept through grid recording
- FASCIA as a one-voice machine, if it fits beside FLEX
- FLEX, the live-buffer machine that replaces BOUNCE, on the new emulator that runs both processors together
