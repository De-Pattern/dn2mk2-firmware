# v0.37 · INTRO

patcher: de-pattern.github.io/dn2mk2/patcher.html

a new start-up animation, a lighter DDRW, and the MAIN resampling fix. big thanks to **s!Rwa²** for the animation, and to \x0x/ and paQ for the preview report.

**fixed / new**
- **start-up animation by s!Rwa²**: 59 frames at the artist's own timing. the gate now checks every frame, in order
- **DDRW is lighter**: same sound, about half the work. it plays **3-note chords** now (was 2)
- **resampling MAIN recorded an empty sample**: fixed. RECORDER with SRC MAIN records the main mix again
- **the sample preview was way too loud** (FUNC + YES, +DRIVE, the recorder's TRIM): it's 6 dB down now, about the level of the same sample on a track
- **polyphonic sample playback**: sample tracks follow the DN2's voice allocation, so you can play chords on ONESHOT, WERP and SLICE tracks like on an FM track (SLICE plays a different slice per note). this has actually worked since v0.35; now it's been checked. voices are shared across all tracks and every voice costs DSP time, so dense sample chords next to PERC and Monomachine tracks hit the voice limit first

**test**
1. power on: the new animation plays through, then the UI as usual
2. a DDRW chord: three notes sound, a fourth drops out cleanly
3. RECORDER, SRC MAIN, with a pattern playing: the recording has the mix in it
4. FUNC + YES preview in +DRIVE: about as loud as the sample on a track
5. a chord on a ONESHOT / WERP / SLICE track: every note sounds
6. everything from v0.36 still

**known issues**
- DDRW: three voices at most
- a P-I or VO-6 voice sometimes goes silent on some units: please run Diagnostics (import page, section 6) when it happens
