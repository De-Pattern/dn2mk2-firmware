# v0.34 · TIMING

patcher: de-pattern.github.io/dn2mk2/patcher.html

the fix for the P-I voices that stayed dead, and the tools to find why they go bad in the first place. thanks misterairplane, Pablo Se7en, blskk and the owner's reports.

**fixed / new**
- **P-I machines silent on the same voices every time** (voice 1, then 4; locked to 1 voice: every note dead): v0.33's safety guard muted a bad voice but never reset it, so once a voice went bad it stayed dead until power-off. now it comes back on the next note
- **the unit tells you what went wrong**: within two seconds of the guard muting a voice, hold FUNC on a PERC or Monomachine page: the tempo's place shows `V1D` (voice 1, bad data in its delay memory) or `V1X` (bad data somewhere else). if you see one, post it with what you were playing
- over USB, a new diag tool (`tools/dn2diag.py`) reads the guard's record and scans the DSP's memory for bad values: the owner will run it; it's how we find the cause
- **the safety checks grew a lot**: the ColdFire emulator now fires the audio interrupt at its real rate while our code runs (it never had), the DSP tests charge memory like the real chip, and a test now poisons a voice on purpose and requires it to come back
- the import page: a folder loads progressively with a count, the two MIDI ports are labelled, more audio formats (AIFF, FLAC, MP3, OGG, M4A)

**test**
1. P-I BD on a PERC track, VOICE SETUP locked to 1 voice, tap: it sounds every time
2. dynamic allocation, tap sixteen times: no voice stays dead
3. if a tap IS silent: hold FUNC right away and read the tempo's place (`V1D` / `V1X`). tell us
4. everything from v0.33's list still: busy PERC/MnM projects, SLICE/GRID YES after MACHINE SEL, +DRIVE preview and folders, the recorder, a fresh and an old project after a power-cycle

**known issues**
- FUNC + YES preview in +DRIVE retriggers while held
- holding SYN doesn't show values on our pages (it does on stock machines)
- LOAD TO PROJ sometimes needs a second load
- B10: another track's LFO menu showing when switching PERC tracks
