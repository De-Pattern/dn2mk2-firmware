# v0.36 · VOICES

patcher: de-pattern.github.io/dn2mk2/patcher.html

more Monomachine voices. thanks misterairplane for the report.

**fixed / new**
- **Monomachine tracks stopped at two voices**: an old fixed limit from v0.26 capped them no matter how much DSP time was free. it's gone; the real-time DSP guard decides now. measured: **SID, VO-6, DENS and DPRO WAVE play 4-note chords**, DDRW plays 2 (it's very heavy)
- **when there isn't room, the oldest voice is dropped cleanly** (silent until its next note) instead of chopping in and out
- DDRW and DENS read their busiest tables from fast memory now: lighter
- the import page has a new **Diagnostics** section (6): if a P-I or VO-6 voice goes silent, run it right after, press Copy and post the result. it only reads from the instrument

**test**
1. dynamic voice allocation, a 4-note chord on SID / VO-6 / DENS / DPRO WAVE: all four sound
2. the same on DDRW: two sound, the rest drop out cleanly
3. lots of overlapping notes on one Monomachine track: the newest always plays
4. everything from v0.35 still

**known issues**
- DDRW: two voices at most for now
- a P-I or VO-6 voice sometimes goes silent on some units: please run Diagnostics when it happens

**coming next (not available yet)**

- a new boot animation by s!Rwa²
- researched for later: parameter slides and instant pattern switch
