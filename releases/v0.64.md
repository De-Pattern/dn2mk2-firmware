# v0.64 · HOLD

patcher: de-pattern.github.io/dn2mk2/patcher.html

keyboard HOLD: hold PTN and press KEYBOARD

**HOLD**
- PTN + KEYBOARD turns HOLD on or off (the screen says KB HOLD ON / OFF while PTN is held)
- it's a sustain pedal on every track: notes keep ringing after you let go
- notes you're already holding when you turn it on get latched
- new notes add to the held ones
- works with the trig keys, MIDI in, chords, microtuning and the arp
- HOLD off releases everything. it starts off after power-up
- PTN and KEYBOARD on their own work as before

**start-up animation**
- now at half the frame rate (same length, same last frame) to make room for HOLD

**please test**
1. hold a chord on the trigs, turn HOLD on, let go: it keeps sounding
2. play more notes: they join the chord
3. HOLD off: everything releases
4. same from a MIDI keyboard
5. arp on, hold a chord, HOLD on, let go: the arp keeps going
6. PTN alone, KEYBOARD alone, PTN + trig, DIRECT JUMP: as before

**known issues**
- arp + HOLD hasn't been tested on hardware yet
- new notes add to the held ones rather than replacing them
- PTN + KEYBOARD no longer switches KEYBOARD mode
- FLEX takes of a single track are about 12 dB too loud at GAIN 0 (v0.63's boost was too much): set GAIN to -12 on FLEX tracks for now. fixed in the next build
- everything listed for v0.63
