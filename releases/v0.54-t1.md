# v0.54-t1 · STEREO (TEST build)

patcher: de-pattern.github.io/dn2mk2/patcher.html (listed under **TEST**)

**This is a test build, not a release.** It is gated exactly like a release, but it comes from the stereo branch so it can be tried on real units. Flash it to test stereo, and go back to v0.53 for everyday use if anything sounds off. v0.53 stays the latest release.

True stereo samples on the sample machines: L and R each go through the voice's whole chain and come out on their own sides

**new**
- stereo samples: import a stereo file in the web tool with **keep stereo** ticked (it shows **ST** in the browser), and the sample machines play it in true stereo. L and R are read from their own channels, and each runs through the voice's filter, overdrive, envelopes and amp with the same settings, out to the track's two sides
- up to four stereo voices sound at once. A fifth plays its mono mix (L + R) / 2
- mono samples and every other machine are untouched

**known issues**
- Comb- and Comb+ play a stereo sample's left side on both sides for now (that filter isn't doubled yet, so it falls back to mono rather than risk anything wrong)
- the FX sends (chorus, delay, reverb) take the left side only
- the recorder still records mono. Stereo samples come from the web tool's import

**please test**
1. in the web tool, tick **keep stereo** and import a stereo file whose sides clearly differ (a hard-panned loop, or a tone in L only). The browser shows **ST**
2. play it on a ONESHOT track on headphones: left comes out left, right comes out right, as in the file. This is the big one
3. the same sample with the filter (Multimode, Lowpass 4, EQ, Legacy LP/HP) and overdrive turned up: both sides change alike, no clicks, no side dropping out
4. four stereo voices (a chord, or four tracks), then a fifth: the fifth plays the mono mix, nothing drops
5. mono samples and stock machines next to it sound exactly as on v0.53

Reports in the usual channel, please. Say which file, which machine and filter, and what you heard.
