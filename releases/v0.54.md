# v0.54 · NAME

patcher: de-pattern.github.io/dn2mk2/patcher.html

Naming your recordings, samples and folders now uses the Digitone's own NAME screen, the same one patterns, sounds and projects use

**changed**
- after a recording, **FILE NAME** is the Digitone's own NAME screen: U/D changes the letter, L/R moves the cursor, FUNC + ARROW opens the letter grid, FUNC + NO deletes, FUNC + YES inserts, SETTINGS makes a random name, and COPY / PASTE / CLEAR NAME are there too
- the +DRIVE browser's **RENAME** (titled SAMPLE NAME) and **CREATE FOLDER** (FOLDER NAME) use it too
- YES saves the name. NO leaves it as it was (a recording keeps its name and goes on to ASSIGN, as before)
- names keep up to 35 characters where the pool keeps long names, in capitals. If the stock screen ever can't open, the mod's own naming screen stands in

**please test**
1. record something, then YES on TRIM: the NAME screen, titled FILE NAME, with the usual key hints along the bottom
2. spell a name with U/D and L/R, try FUNC + ARROW (the grid) and SETTINGS (random). YES: on to ASSIGN, and the sample has that name in the list and on the +Drive
3. record again and press NO on the NAME screen: on to ASSIGN, with the name it had
4. +DRIVE, a sample, RENAME: YES renames it, NO leaves it
5. CREATE FOLDER: YES makes the folder with the name you gave it
6. a name longer than 16 characters: the screen scrolls, and all of it is kept
