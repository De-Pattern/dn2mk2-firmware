# v0.55 · FLEXPOOL

patcher: de-pattern.github.io/dn2mk2/patcher.html

The eight FLEX buffers are now at the end of the sample list on every sample machine, so any ONESHOT, WERP, STRETCH, REPITCH, GRID or SLICE track can play a FLEX take. MUTE SRC also waits for the first take before muting

**changed**
- **FLEX buffers B1..B8 in SAMP**: turn SAMP past 127 and it goes on to B1..B8. The sample list shows them after slot 127, as "FLEX BUF n" when the buffer holds a take or "FLEX EMPTY n" when it doesn't. UP/DOWN in the list steps through them too
- a track on Bn plays that buffer's current take, the same one the FLEX track plays. When a new take lands, it switches to the new one. An empty buffer plays nothing
- SAMP p-locks can pick a buffer, so one trig can play a FLEX take and the next a pool sample
- page 2 shows FLEX BUF n / FLEX EMPTY n where the waveform would be
- **MUTE SRC waits for a take**: with MUTE ON, the SRC track stays in the mix until its FLEX buffer holds a take, then mutes, so FLEX's loop takes over. Before, it muted straight away and left a gap. After CLEAR BUF you hear it again

**please test**
1. record a FLEX take into BUF 01. On another track, ONESHOT, SAMP all the way up: past 127 to B1. Play it: it's the take
2. the sample list (turn SAMP): B1 reads FLEX BUF 1, B2 reads FLEX EMPTY 2. UP/DOWN moves between 127, B1 and B2
3. record a new take into BUF 01 while the ONESHOT track plays B1: it switches to the new take, the same as the FLEX track does
4. STRETCH or SLICE on B1: STRETCH fits the take to its BARS, and SLICE slices it
5. p-lock SAMP to B1 on one trig and a pool sample on the next: each trig plays its own
6. MUTE SRC ON with no take yet: the SRC track is still heard. Record the first take: it mutes, and FLEX plays the loop. CLEAR BUF: the track comes back
