## **OUTBOX 8 USERS: THIS ONE IS FOR YOU. PLEASE TEST IT.**

**This is a TEST build:** the whole DN2 mk2 mod, v0.72 LIGHTER with nothing removed, now on Elektron's **OS 1.12** instead of 1.11.

1.12 is Elektron's release that lets the **main outputs go through Outbox 8**, and adds [FUNC] + [UP]/[DOWN] to move between channels in Outbox 8's channel menus. Until now the mod was built on 1.11, so you had to choose between the mod and that routing. Now you get both.

Your unit stays on 1.12: no downgrade.

**what changed**
- the mod runs on stock OS 1.12. Only the main ColdFire program differs between 1.11 and 1.12; the DSP program, the Outbox 8's own firmware, the bootstrap and the updater are byte for byte the same in both
- every place the mod touches was moved onto 1.12 and checked against both OS files. The whole gate ran again on 1.12, emulator steps included, on new 1.12 emulator snapshots
- the patcher asks for **both** Digitone II files, 1.11 and 1.12 (both free from Elektron). The mod is built on 1.11 as always, then moved onto 1.12, and the page checks the result byte for byte against the cleared file

**please test, Outbox 8 users first**
1. **main outputs through Outbox 8** (Elektron's 1.12 routing): set it up, play a kit with mod machines (PERC, Machinedrum/Monomachine, sample tracks): does it come out where you routed it?
2. **per-track Outbox outputs:** route a few tracks with mod machines on them to their own outputs. Is each one on its own output, at the right level?
3. [FUNC] + [UP]/[DOWN] in Outbox 8's channel menus
4. everyone: does your usual v0.72 project load and play as before? MACHINE SEL, the sample pages, FLEX recording, PERFORM, the arp in key
5. anything that behaves differently from v0.72 on 1.11

**known issues**
- untested on hardware: this is the first build on 1.12. Back up the +Drive and your projects first
- the emulator can't run an Outbox 8, so the Outbox routing itself has only been tested by Elektron, on stock 1.12
- everything listed for v0.72
