# v0.69 · PERFORM

patcher: de-pattern.github.io/dn2mk2/patcher.html
manual: de-pattern.github.io/dn2mk2/mod-manual.html

Analog Four-style performance macros, and a DSP limit in MACHINE SEL

**PERFORM**
- hold [MOD] and press [FX]: eight macros, A–H, one per knob
- each macro moves up to five parameters at once, on any tracks, each with its own depth
- a macro is an offset: the sound's own setting, its LFOs and p-locks stay, and the macro is added on top
- push a knob (or YES) for MODULATION SETUP: A–E each target's depth, F its track, G its parameter, H the macro's value; push H for BIPOLAR; YES renames the macro; FUNC + NO clears it
- FUNC + YES on the PERFORM page is PERF MUTE: every macro out at once, and back
- saved with the project
- [MOD] + [FX] again, NO or any page key closes it

**DSP limit**
- MACHINE SEL now refuses a machine that would take the kit past what the DSP can run, and says DSP LIMIT; the track keeps the machine it had
- roughly three VO-6 tracks, two DENS, seven PERC or eleven sample tracks, or a mix that adds up the same
- stock machines weigh nothing, and a lighter machine is always allowed
- kits saved before v0.69 load as they are

**please test**
1. [MOD] + [FX] opens PERFORM, again closes it; NO and the other page keys close it too
2. set a macro with two targets on two tracks (say one track's filter cutoff and another's decay), turn its knob: both move, and the sound's own value comes back at 0
3. BIPOLAR: the value runs −64..+63, a negative depth moves the other way
4. PERF MUTE: the macros drop out and come back
5. rename a macro, save the project, power-cycle, reload: the macros are as you left them
6. a second project keeps its own macros
7. three VO-6 tracks, then a fourth: DSP LIMIT, and the fourth keeps its machine; a stock machine or a lighter one on it is allowed
8. does a kit inside the limit ever drop notes? (the load meter: hold FUNC on a PERC or Monomachine page)
