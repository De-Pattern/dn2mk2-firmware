# v0.61 · MICROTUNING

patcher: de-pattern.github.io/dn2mk2/patcher.html

microtuning: a tuning per project, switched on per track

**new: TUNE on KB SETUP**
- FUNC + KEYBOARD: the empty H knob is now TUNE. turn it to tune the active track (OFF or a tuning), push it to open the TUNING page
- factory tunings: 12-TET, Just Major, Just Minor, Pythagorean, Meantone 1/4, Werckmeister III, Kirnberger III, Vallotti, Arabic Rast, Poole Rod12, Poole12 Min, plus 8 USER slots of your own
- everything played on a tuned track is retuned voice by voice: keyboard, trigs, chords, arp, slides. MIDI tracks and MIDI out stay 12-TET. KB SETUP's SCALE, ROOT and MODE work as before

**TUNING page** (push H)
- A TUNE, B ROOT, C TRK (this track on/off), D ALL (every track on/off). the 16 boxes show which tracks are tuned
- YES on a USER tuning opens EDIT, NO closes. the trig keys and keyboard play through, so you can tune by ear

**EDIT page** (YES on a USER tuning)
- A NOTE (LEFT/RIGHT step it too), B CENT, C .1CT (tenths of a cent), D FROM
- FUNC + YES copies FROM into the slot (copy 12-TET to reset it). NO goes back

the tuning is saved with the project (two seconds after the last change, and before LOAD or NEW) and comes back on LOAD and at power-on

**please test**
1. FUNC + KEYBOARD: H says TUNE OFF; turning it lists the tunings; H on the main page is unchanged
2. a tuned track against an untuned one playing the same chord: you hear the difference
3. TUNING: ROOT moves the tuning; TRK and ALL switch tracks
4. a USER slot: EDIT a note's CENT and .1CT, FUNC + YES copies FROM, NO, NO closes
5. LOAD another project and back, then a power cycle: the tuning, ROOT, tracks and USER slots are kept
6. chords, arp and slides on a tuned track
7. a SLICE or GRID track is never retuned

**known issues**
- ERASE MOD DATA doesn't clear tunings yet: a project's tuning survives an erase
- one tuning per project; USER slots can't be renamed
- SLICE and GRID tracks are never retuned (their note picks the slice)
