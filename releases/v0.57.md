# v0.57 · FLEXMUTE

patcher: de-pattern.github.io/dn2mk2/patcher.html

FLEX's MUTE SRC now follows the FLEX track: the source is muted only while the FLEX track is actually playing its take

**changed**
- **MUTE SRC**: with MUTE ON, the SRC track stays in the mix while you record, and drops out only while the FLEX track plays the take. When the FLEX note ends (or you stop or mute the FLEX track), the SRC comes back within about 0.2 s. No more tracks stuck muted until a power cycle (thanks NiKo)
- the old REC 1 / REC 2 names at 124/125 are gone from the sample list (the FLEX buffers are B1–B8 at the end of the list)
- a sample track playing a FLEX buffer shows **F** as its bank letter beside B1–B8

**please test**
1. FLEX track, SRC TRK n, MUTE ON. record a take: track n is still heard while recording
2. play the FLEX track (a trig or the keyboard): track n drops out. stop or mute the FLEX track: track n comes back
3. MUTE OFF: track n comes back right away
