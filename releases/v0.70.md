# v0.70 · INKEY

patcher: de-pattern.github.io/dn2mk2/patcher.html
manual: de-pattern.github.io/dn2mk2/mod-manual.html

arp scale lock, in-key track transpose, and a PERFORM fix

**arp scale lock** (w-winter's arpscale)
- SETTINGS > PERSONALIZE > ARP OFS IN SCALE (off by default)
- on: each arp step's offset counts degrees of the track's KB SETUP scale from its root, not semitones. In C major, E + 2 plays G (stock plays F#), + 7 is the octave
- offset 0 plays the held note as it is; a held note off the scale moves to the nearest scale note first
- in the ARPEGGIATOR menu, [UP] on an active step marks it to move in semitones (a plus in the step graph); [DOWN] removes the mark
- SCALE CHROMATIC and MODE CHORD MEMORY stay stock

**in-key transpose** (w-winter's degreetranspose)
- [KEYBOARD] + [FUNC] + [+]/[-] (or [KEYBOARD] + [TRK] + [+]/[-]) moves the active track by degrees of its scale, -7..+7, one a press
- it blinks while held, takes effect on release, and shows in the track box with a tick ("+2'")
- kept per track in each pattern, MIDI tracks too; a track with no scale moves by semitones
- [KEYBOARD] + [TRK] + [FUNC] + [+]/[-] is stock's octave

**PERFORM fix** (thanks Dubmaster)
- v0.69's macros could move the wrong track or nothing, and worked only on some trigs: they wrote the voice with the track's number, but a track's notes play on any free voice
- now each target moves every voice playing its track

Both in-key features are w-winter's mods from upstream (angellinares/dn2_firmware_explore), applied as they are. Thanks to edtide for asking and calliomilope for pointing the way.

**please test**
1. ARP OFS IN SCALE on, a scale in KB SETUP, an arp with offsets: the notes stay in key; off: as before
2. mark a step with [UP] in the ARPEGGIATOR menu: it moves in semitones
3. [KEYBOARD] + [FUNC] + [+] twice: the track plays two degrees up, "+2'" in its box; save, reload: still there
4. the same on a MIDI track
5. PERFORM: a macro on two tracks while a pattern plays: every trig of both tracks moves, nothing else does
