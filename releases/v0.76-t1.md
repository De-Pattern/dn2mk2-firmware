# v0.76-t1 · STEREO (TEST build)

patcher: de-pattern.github.io/dn2mk2/patcher.html (listed under **TEST**)

**This is a test build, not a release.** It is gated exactly like a release, but it comes from the stereo branch so it can be tried on real units. It is v0.76 FLOW with stereo samples added. Flash it to test stereo, and go back to v0.76 for everyday use if anything sounds off. v0.76 stays the latest release.

**please test stereo.** this is the second try at true stereo samples. the first (v0.54-t1) was pulled after your reports, and every one of them was followed up

**new**
- stereo samples: import a stereo file in the web tool with **keep stereo** ticked (it shows **ST** in the browser), and the sample machines play it in true stereo. L and R each run through the voice's filter, overdrive, envelopes and amp with the same settings, out to their own sides
- up to four stereo voices sound at once. a fifth plays its mono mix (L + R) / 2
- PREVIEW plays a stereo sample in stereo, and SLICE finds the slices of a stereo sample
- mono samples and every other machine are as in v0.76

**fixed since v0.54-t1**
- a stereo track sent a gain level instead of its sound to the main outputs and the FX sends: the silent track, the click on every retrigger, and most likely the other tracks dropping out and the silence after a power cycle. each side now reaches the main outputs and the sends as it does the track outputs
- checked in the emulator on both processors: a stereo note's left side is exactly the same note played from a mono file of its left channel, and its right side the one from its right channel, at the track outputs and at the main outputs and sends. v0.54-t1 fails that same check

**please test**
1. in the web tool, tick **keep stereo** and import a stereo file whose sides clearly differ (a hard-panned loop, or a tone in one side only). the browser shows **ST**
2. play it on a ONESHOT track on headphones: left comes out left, right comes out right, as in the file
3. let an FM Tone track play next to it the whole time: it sounds on its first trig, every trig, and nothing drops out
4. retrigger the stereo sample quickly, then play chords (two, three, four notes): no clicks, no side going silent, no other track dropping out. **the emulator can't check this one: it only hears the first voice after power-on**
5. a fifth stereo voice: plays the mono mix, nothing drops
6. save the project, power cycle, play it again: everything sounds, the other tracks too
7. PREVIEW a stereo sample in the browser, and SLICE it (16 slices)
8. the FX sends (chorus, delay, reverb) on the stereo track: both sides go in

Reports in the usual channel, please. Say which file, which machine and filter, and what you heard. If anything goes silent, a power cycle and v0.76 bring it back.
