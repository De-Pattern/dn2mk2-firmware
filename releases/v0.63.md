# v0.63 · FLEXLEVEL

patcher: de-pattern.github.io/dn2mk2/patcher.html

FLEX takes at the level you hear, and saving FLEX no longer blows the level up

**FLEX level**
- a FLEX take of a single track (SRC TRK) now plays back about as loud as the track was in the mix, with GAIN at 0. no more boosting to hear it
- heads up: if you had turned GAIN up on a FLEX track before, it will now be 24 dB hotter. set GAIN back to 0
- MAIN and IN takes are unchanged for now

**FLEX save**
- saving the FLEX buffer to a slot no longer normalises it. before, it normalised the very take the FLEX track was playing, so it jumped to full scale. the saved sample now matches the take
- SAMPLING and other recordings are still normalised as before

**please test**
1. FLEX from a single track, GAIN 0: the take is about as loud as the track was
2. a FLEX track you had boosted: now louder, GAIN 0 brings it back
3. save the FLEX buffer while it plays: no level jump, and the saved sample loads at the same level
4. SAMPLING + save: still normalised
5. MAIN and IN takes: same as v0.62

**known issues**
- MAIN and IN takes are still on the quiet side
- everything listed for v0.62

**Coming next (not available yet)**
- MAIN and IN FLEX takes at the level you hear
- a keyboard HOLD (PTN + KEYBOARD), once there's room for it in the firmware
- arp scale lock
- the per-track EQ is dropped for now (the firmware is nearly full)
- DT2 presets are on hold for now
