MIDI Arpeggiator

Use the Digitone II arpeggiator on MIDI tracks. The ARPEGGIATOR menu opens, and the arp plays your external gear over MIDI. Pick your firmware, download a signed image.

Everything happens in this tab. Your firmware file is never uploaded — this page has no server to upload it to. It is static files on GitHub Pages; you can read every line in the repository.

Prove your way back before you flash anything. The Early Start-up Menu reflashes stock firmware over MIDI. Do that once, with an unmodified image, before you flash a modified one — and back up your +Drive, which no tool here can recover.

What changes

Menu
[FUNC]+[ARP] opens the ARPEGGIATOR menu on a MIDI track, and its knobs stay on it
Playback
With the arp on, the track's trigs and held keys arpeggiate and go out on the track's MIDI channel
Follows
MODE, SPD, RNG, N.LEN, LEN, the step mask and note offsets — the settings a synth track uses
Arp off
The MIDI track behaves as stock; synth tracks are untouched
Writes
—

Confirmed on a Digitone II, 2026-09-17, captured from its MIDI output at 120 BPM with SPD 1/16. Offsets and velocity came through, steps arrived every 125 ms, and no note stuck across 5,248 note messages. Note lengths follow N.LEN:

Build it

The image is rebuilt, re-signed with the key derived from your own file, and every integrity field is checked again. Nothing downloads unless all of them pass.

Combining with other mods

Each page applies one mod. To combine them, build here, then load the downloaded file into the next page — in any order. This mod writes a few edits and one block of new code inside section 3, changes no length and appends nothing.

  • LFO Waves — combines. No shared bytes, and neither changes the other's code.
  • Modulation Destinations — combines.
  • Transient Swapper — combines; it only writes the DSP image.
  • A Fourth LFO — combines. Build it last, as it asks.

What "combines" means here. The bytes each mod writes are checked not to overlap, and chaining all three section 3 mods rebuilds and verifies, with the same result in the browser as on the command line. The arpeggiator on its own was tested on hardware; a combined image has not been flashed yet.
