FX Modulation

Point an LFO at the Chorus, the Delay or the Reverb. Twenty-four new entries in the DEST list, chosen by name. Pick your firmware, download a signed image.

Everything happens in this tab. Your firmware file is never uploaded — this page has no server to upload it to. It is static files on GitHub Pages; you can read every line in the repository.

Prove your way back before you flash anything. The Early Start-up Menu reflashes stock firmware over MIDI. Do that once, with an unmodified image, before you flash a modified one — and back up your +Drive, which no tool here can recover.

What opens

All twenty-four, or none. Every address this mod writes is checked to hold its stock bytes first, and so are twenty-six more it only reads; an image that differs anywhere is refused rather than written somewhere plausible.

Where
On a synth track: [MOD], an LFO, turn DEST. They sit after the FX group, before the rest
Global
These are the machine's one Chorus, Delay and Reverb. Every track's LFO can aim at the same one, and they add up — that is what "global" means here, not a fault
Not included
Master. Its slots need destination codes above 127, and the firmware widens that byte as signed, so it needs a different edit
Writes
—

Confirmed on a Digitone II, 2026-09-23. An LFO on a synth track was pointed at Delay Feedback Gain and the delay's feedback followed it, with DEP and SPD doing what they should. The owner's words: “works :) I can modulate with the LFOs the parameters.”

One extra fix rides along. Stock firmware has no short name for the Chorus group in its own group → name table — the slot holds the out-of-range fallback, which reads ERR. So the first build showed ERR over the Chorus entries while Reverb and Delay read REV and DEL. This mod points that one slot at CHR, the short name Chorus's own Mix Vol. record already carries. Reverb and Delay are untouched.

Build it

The image is rebuilt, re-signed with the key derived from your own file, and every integrity field is checked again. Nothing downloads unless all of them pass.

Combining with other mods

Each page applies one mod. To combine them, build here, then load the downloaded file into the next page — in any order, except that A Fourth LFO goes last. This mod writes a few edits and one block of new code inside section 3, changes no length and appends nothing.

  • Modulation Destinations — combines. Different records, different bytes.
  • LFO Waves — combines. New waveforms to aim at these destinations with.
  • MIDI Arpeggiator — combines. No shared bytes.
  • Transient Swapper — combines; it only writes the DSP image.
  • A Fourth LFO — combines, built here first. LFO4 copies the table this mod opens records in, so this page refuses an image LFO4 has already built.

What "combines" means here. The bytes each mod writes are checked not to overlap, and that is the only guarantee offered. This mod was tested on hardware on its own; a combined image has not been flashed.
