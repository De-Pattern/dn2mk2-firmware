6 · Firmware

The mod itself (the sample machines, the recorder, PERC and the rest) is a Digitone II OS 1.11 update file, DN2mod_vX.Y_NAME_OS1.11.syx. Every build is checked by the project's ship gate before it is published, and only that exact file (its sha256) is cleared. Flash it as any Digitone II OS update (Elektron Transfer, or the instrument's SysEx receive), after backing up the +Drive. The DN2 Mod Patcher builds it in your browser from your own copies of Elektron's stock OS files (Digitone II 1.11, Digitakt II 1.17, Machinedrum UW 1.63), and lets you save it only if it is byte for byte the cleared file. Each version's notes and tests: FIRMWARE.md.
